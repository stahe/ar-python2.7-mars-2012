## 📌 نظرة عامة

يقدم هذا المشروع مجموعة من نصوص Python التي تغطي مجالات تقنية متنوعة. لا يُعد هذا دورة نظرية، بل **مجموعة من الأمثلة العملية** المصممة لتقديم مقدمة سريعة.

### الموضوعات التي يتم تناولها:

**أساسيات** لغة Python.

* إدارة قواعد بيانات **MySQL**.

* برمجة شبكات TCP/IP

* برمجة **الويب**.

* **البنى ثلاثية المستويات** والبرمجة القائمة على **الواجهة**.
